VMixRemote

A SwiftUI rebuild of the VMix mixer-remote idea with a clean mixer core, CoreMIDI integration, hardware-free mock MIDI, and JSON profile storage.

Install with Homebrew View source

Install

Install the MVP from Homebrew.

The formula builds the SwiftPM app target, stages a macOS app bundle, and installs a small `vmix-remote` launcher.

brew tap frederikschulze1701-blip/vmixremote brew install vmix-remote vmix-remote

MVP

Built for a real desktop mixer workflow.

Eight channel strips

Faders, meters, mute, solo, select, and channel names in a resizable macOS window.

CoreMIDI ready

Device discovery, connection state, send/receive paths, and MIDI activity logging.

Mock MIDI first

Hardware behavior is testable without a connected mixer, so core updates stay reliable.

Profiles

Codable JSON profiles live in Application Support, with import, export, and legacy path migration.

Architecture

SwiftUI on top, platform-neutral core underneath.

VMixRemote separates mixer state, MIDI mapping, profile persistence, CoreMIDI backends, and SwiftUI views into independent SwiftPM targets.

Read architecture notes
  1. VMixCoreMixer model, channels, EQ, faders, MIDI messages, and profiles.
  2. VMixMIDIMock MIDI and CoreMIDI behind a shared backend protocol.
  3. VMixRemoteAppSwiftUI views, view model orchestration, and macOS app shell.

Name note

This repository is a native macOS mixer remote. It is not affiliated with fenfenfenfan/VMix, the research project “Improving Text-to-Image Diffusion Model with Cross-Attention Mixing Control,” and it does not copy that project’s unlicensed assets or text.
